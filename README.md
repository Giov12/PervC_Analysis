# Helper Scripts used in Benjamin et al. (2026)

This repository contains helper scripts used in the study **[Genomic Validation of PERV‐C‐Free Pigs to Support Xenotransplantation](https://pmc.ncbi.nlm.nih.gov/articles/PMC12810672/)**.

## About the files
The repo contains custom python scripts used when exploring the PacBio sequencing data produced in the study.
Most of the analyses used published tools such as minimap2, samtools, and klumpy.
